# 从「校徽 + 一只奶龙」做出一整套跳转页

> **给 AI agent 的执行手册。** 换一所学校 = 问清几个问题 → 填 `config.json` → 跑一条命令。
> 页面 HTML 也是模板生成的，不要手改 `site/*.html`（会被下次生成覆盖）。

---

## 0. 第一步：问用户（**先问，不要猜**）

> ⚠️ **本仓库自带的 `config.json` 是「中国奶龙大学.org → 湖州师范大学」那一份实例，
> 不是你要做的那所学校。** 如果你接到的不是这个学校，开工前第一件事就是把它改掉。
> 尤其**「奶龙大学」这个名字**——每所学校叫法都不一样，**绝对不要沿用示例里的
> 「中国奶龙大学」**，必须问用户。

一次性把下面这张表问完。用户答不上来的项，标注「这个我可以自己去官网查」，
能查的就去查（见第 2 节），**别让用户替你干查资料的活**。

| # | 要问的 | 为什么需要 | 用户没答时能不能自己查 |
| --- | --- | --- | --- |
| 1 | **正式学校名**（真实的那所大学，中文） | 文案里「把你送到 XX 官网」、署名 | 能从官网查，但要跟用户确认（有的学校刚更名） |
| 2 | **恶搞学校名**（「XX 奶龙大学」，见「命名怎么问」） | **首页那个大标题就是它** | ❌ **必须问**，绝对不要沿用示例值 |
| 3 | **域名** | 生成 canonical / og:image / 「关于」文案 | ❌ 必须问 |
| 4 | **最后要跳到哪个网址** | 页面 2.6 秒后的跳转目标 | 能从第 1 项推出，但要确认（有的学校是 `www.` 有的是裸域） |
| 5 | **一张校徽图**（或官网首页地址，自己去扒） | 生成 `ring.webp` / 校徽旁边的奶龙 | 能给官网地址就行 |
| 6 | **一张奶龙图**（白底最省事） | 徽章中心那只 | ❌ 必须用户提供（涉及版权，别自己去网上抓） |
| 7 | **主色**：奶龙黄 `#fece0e` 还是校徽本色 | 徽章整体配色 | 默认奶龙黄，问一句就行 |
| 8 | 校训 | 备选版式里那行「校训：xxx」 | 能从官网/校徽查 |
| 9 | 学校英文名 / 拼音 | 备选版式的英文小字 | 能从官网查 |
| 10 | 要不要在页面署名 | 备选版式右下角那行 | 默认写「非官方粉丝站点」 |

可以直接把下面这段发给用户：

> 我照「中国奶龙大学」那种跳转页给你做一份。给我这几个信息就行：
> ① 你们学校**正式**叫什么（官网现在用哪个名字，我去核对）
> ② **恶搞名要不要改**——首页那个大标题。示例是「中国奶龙大学」，
>    是沿用还是改成你们学校对应的？（常见叫法是「城市名/地区 + 奶龙大学」，
>    比如「哈尔滨奶龙大学」「湖州奶龙大学」；也可以自己起）
> ③ 域名 ④ 最后跳到哪个网址
> ⑤ 校徽图（或官网地址，我自己扒）⑥ 一张奶龙图（白底最好）⑦ 主色要奶龙黄还是校徽原色
> ⑧ 校训（可选）⑨ 页面底部要不要署名。
> 校徽、校训、英文名这些能自己查的我就自己查了，不确定的再问你。

**开工前必须拿到**：1、2、3、4、5、6。其余的可以先用默认值生成，再让用户看图提意见。

### 两个名字，别搞混（第 1、2 项展开）

这个页面里**同时存在两个学校名**，都可能是用户想改的，**两个都要问一遍「要不要改」**：

| | 字段 | 长什么样 | 出现在哪 |
| --- | --- | --- | --- |
| **恶搞名** | `site_title` | 中国奶龙大学 / 哈尔滨奶龙大学 | **首页 h1 大标题**、浏览器标签、`og:title`、状态文案「奶龙正在护送你前往 ___」 |
| **正式名** | `school_name_cn` | 湖州师范大学 / 大连理工大学 | 「会先加载此页面，把你送到 ___ 官网」、署名「与 ___ 无官方关联」、og 卡片副标题 |

一句话记住：**首页顶着的是恶搞名，文案里说的和真正要去的都是正式名。**
所以打开 `中国奶龙大学.org` 看到的是「中国奶龙大学」，但底下写着「把你送到湖州师范大学官网」。

问的时候两句话都要问到：

> ① 你们学校**正式**叫什么？（我去官网核对）
> ② 这个奶龙大学**恶搞名**要不要改？现在示例叫「中国奶龙大学」。
>    是要沿用，还是改成「哈尔滨奶龙大学」这种？

⚠️ 常见的翻车：只改了一个。
- 只改恶搞名 → 「哈尔滨奶龙大学」的页面却写着「把你送到湖州师范大学官网」
- 只改正式名 → 「哈尔滨奶龙大学」的页面却写着「把你送到大连理工大学官网」

`tools/build-site.py` 生成前会把这两行都打出来，逐行核对一遍再往下走。

### 恶搞名怎么起（第 2 项展开）

「奶龙大学」是个梗名，**每所学校都不一样**，没有默认值可以套。问的时候把选项摆出来：

| 用户可能想要的恶搞名 | 例子 | 对应 `site_title` |
| --- | --- | --- |
| 沿用「中国奶龙大学」 | 就是本仓库这套名字 | `中国奶龙大学` |
| 城市/地区 + 奶龙大学 | 哈尔滨奶龙大学、湖州奶龙大学、大连奶龙大学 | `哈尔滨奶龙大学` |
| 完全自定义 | 「奶龙大学」「XX 大学奶龙分校」 | 用户给什么写什么 |

连带要确认的还有两处（都在 `config.json`，改一个 `site_title` 会自动同步）：

- `site_title_en`：备选版式里那行英文小字（如 `China Nailong University`），
  用户没想法就用学校英文名；
- 域名本身往往就含这个名字（`中国奶龙大学.org`），**域名和站名不一致是正常的**，
  但值得跟用户对一句，免得他要的是「哈尔滨奶龙大学」却给了个「中国奶龙大学」的域名。

**兜底**：`tools/build-site.py` 每次生成前会打印一份「将要生成的站点」清单，
并在**域名/学校/跳转目标已经换掉、但站名还是示例值**时报警：

```
  ⚠️  配置自检：
    · 域名/学校/跳转目标已经换掉了，但「奶龙大学」的名字还是示例的「中国奶龙大学」。
      —— 这个名字必须问用户：是沿用「中国奶龙大学」，还是改成 XX 奶龙大学？
```

看到这条就说明你漏问了，回去补。

## 1. 先侦察（拿到答案之前就能做的功课）

```bash
# 域名现在是什么行为？（决定要不要拆 301，见 docs/01-deploy-cloudflare.md）
curl -sSI "https://<用户的域名>" | sed -n '1p;/^[Ll]ocation/p'

# 拿到学校官网首页，找校徽和基本信息
curl -sS "https://www.<学校>.edu.cn/" -o /tmp/school.html
grep -oiE '(src|href)="[^"]*(logo|xiaohui|emblem)[^"]*\.(png|svg|jpg)"' /tmp/school.html | sort -u
grep -oE '<title>[^<]*</title>' /tmp/school.html
```

看官网时顺手确认这几件事，别抄错：

- **学校现在叫什么**——官网 `<title>` 和校徽上的字可能和用户嘴里说的不一样（更名很常见）。
  `grep -c '旧名字' /tmp/school.html` vs `grep -c '新名字'` 一比就知道。
- **校训**——一般在校徽中心的篆字、或「学校简介」页面里。
- **建校年**——校徽里通常印着（如 `1916`）。
- **校徽在 logo 图里的位置**——官网的 `logo.png` 常常是「校徽 + 毛笔字校名 + 英文名」一横排，
  校徽是最左边那个正方形。记下它的 `[左, 上, 右, 下]` 填进 `logo_emblem_box`。

## 2. 填 `config.json`

每个字段的含义在文件里都有注释。要点：

| 字段 | 说明 |
| --- | --- |
| `homepage` | 哪套版式当首页：`index`（旋转校徽环，默认）或 `mascot`（校徽旁一只奶龙）。另一个会生成到 `/mascot.html` 或 `/rotate.html` |
| `site_title` | 「中国奶龙大学」这种（**恶搞名**） |
| `school_name_cn` / `school_name_en` / `school_motto` / `school_founded` | 真实学校信息 |
| `target_url` | 页面最后跳哪（**记得带结尾斜杠**，和学校官网一致） |
| `domain` | 中文域名直接写中文，脚本自己转 punycode |
| `site_title_en` | 备选版式里那行英文，没有就用学校英文名 |
| `intro_line` / `og_subtitle` / `about_p1` / `about_p2` / `credit` | 文案，支持 `{school}` `{site}` `{domain}` `{school_del}` 占位符 |
| `about_del_after` + `about_del_text` | 「湖州师范大学」→「湖州<del>奶</del>师范大学」这种玩笑：在前缀后面**插入**一个划掉的字。前缀对不上就原样输出，不会搞坏页面 |
| `steps` | 备选版式进度条依次显示的文案 |
| `ink_rgb` | 徽章主色。奶龙黄 `[254, 206, 14]`；想用校徽原色就填校徽的墨色，比如 `[151, 30, 35]` |
| `logo_file` / `logo_emblem_box` | 校徽原图 + 校徽在其中的位置 |
| `nailong_file` | 奶龙原图 |
| `ring_*` / `core_*` | 徽章几何，默认值照抄参考站，换校徽一般不用动 |

把两张原图放进 `assets-src/`（文件名随便，和 config 里对上即可）。

## 6. 流水线内部在做什么（要调参时看这里）

### 6.1 `ring.webp` —— 把校徽变成可旋转的文字环

1. 在 `logo_emblem_box` 里，用 alpha > 0.25 的像素**逐角度取最外缘**，得到 360 个边界点；
2. 对这些点做 **Kasa 最小二乘圆拟合**，得到圆心 `(ox, oy)` 和外径 `R`（残差打印出来，> 3px 说明校徽不是正圆或框没框准）；
3. 以拟合圆心裁正方形，缩放使外径 = `ring_outer`（默认 355）；
4. 把墨色**换成主色**：原图的 alpha 就是「墨量」，用它把主色压到白色环面上 → 得到白底 + 彩色文字；
5. **挖空中心**：半径小于 `ring_cut_ratio × R` 的像素 alpha 归零，只保留最内圈那根细圆环之外的部分。

几何默认值（外径 355 / 挖空到 0.686R）是**照抄参考站** `nailong.dykey.net` 的，所以生成的
`ring.webp` 能和参考站的直接互换。

### 6.2 `core.webp` —— 奶龙进徽章

1. 从图片四边**洪水填充**接近白的区域（阈值 238），得到背景掩膜 —— 这样奶龙**内部**的白色高光不会被误伤；
2. alpha 羽化 0.7px，然后**反预乘**去掉边缘残留的白边（`out = (rgb - 255(1-a)) / a`）；
3. **下缘淡出**：最后 `1 - core_fade_from` 的高度做 smoothstep 到全透明 —— 奶龙原图往往是拦腰截断的，不淡出的话放进圆形徽章里会像被刀切；
4. 按 `core_width` 缩放、摆到画布中心偏下一点；
5. 如果离画布中心的最大半径超过 `core_max_radius`，**整体缩小**——否则会压到会旋转的文字环。

### 6.3 两个页面的结构

`templates/index.html.tmpl`（仿 `中国奶龙大学.com`）：

- 三层同心：`.badge::before` 白色圆盘 → `.core` 奶龙（呼吸动画）→ `.ring` 文字环（WAAPI 无限旋转）
- `.progress` 那一圈是 SVG `stroke-dashoffset` 倒计时，`--delay` 由 JS 注入
- 2.6 秒后 `location.replace(TARGET)`；点任意处 / 按任意键立刻走；右下角「关于」打开时**暂停倒计时**，关掉接着走
- 无障碍：`prefers-reduced-motion` 时关掉动画并缩短停留；没 JS 时 `<noscript>` 里的 meta refresh 兜底

`templates/mascot.html.tmpl`（仿 `哈尔滨奶龙大学.com`）：

- 卡片 + `mascot.png` + 进度条 + 依次切换的 `steps` 文案 + 「跳过动画直接前往」
- `AUTO_REDIRECT = false` 可以预览不跳走

两个页面都是**纯静态、零依赖**（两个 HTML + 5 个图片）。

## 7. 踩过的坑（都是实际踩的）

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| 学校刚更名 | 用户说「湖州师范学院」，官网和校徽已经是「湖州师范大学」 | 以官网 `<title>` 和校徽上的字为准，再跟用户确认 |
| 中文域名的绝对 URL | `og:image` 写中文域名可能不被某些平台解析 | 生成时统一转 punycode（`punycode()` 已处理） |
| 资源用了相对路径 | 站点在任意路径下都要返回本页时，`ring.webp` 会 404 | 页面里统一用 `/ring.webp` 这种绝对路径，**所以必须部署在域名根目录** |
| 手改 `site/*.html` | 下次 `build-site.py` 一跑就没了 | 改模板或 `config.json` |
| 缺少中文字体 | `og.jpg` 上出现豆腐块 | `_font()` 会退回默认字体；真缺字就装字体，或把标题改短 |
| 图片生成工具不可用 | 没法「画」一只奶龙 | 不用画，让用户给图；本项目就是这么来的 |
| 奶龙原图是「拦腰截断」的 | 直接放进圆徽章像被切了一刀 | `core_fade_from` 下缘淡出 |
| 奶龙太大 | 盖住了会旋转的校名文字环 | `core_max_radius` 自动缩，日志会打印缩了百分之几 |
| 校徽不是正圆 / 框歪了 | 拟合残差 > 3px，挖空后边缘歪 | 调 `logo_emblem_box`，看打印的残差 |
